Madlibs-Program

An interactive Python program that prompts for words, then prints a one paragraph story about a man named Joe built from those answers. This page is the tavern song book: the keeper writes down who sang, and what the verses asked for.

The repo on GitHub Running it

First page: how a round works, laid out as verses

The program asks for five words, one at a time, in this order. Each line is a verse, and the blank stays blank until the player fills it.

Verse one, a verb 
Verse two, an adjective 
Verse three, a noun 
Verse four, a verb ending in ed 
Verse five, one final verb 

Leading and trailing whitespace on each answer is stripped before the story is printed. The words are used exactly as typed apart from that: nothing checks that a verb really is a verb.

Second page: the reveal

Madlib: Joe is Going to swim, Joe is really brave, Unfortunately, Joe got into trouble with a dragon, If Joe were to leave now, he would certainly get grounded, Joe now has a bicycle.

The fixed story text stays indigo; the supplied words are picked out in brass. One story, one character, and the template never changes. Only the five words do.

Two endings hide in the noun verse. Enter the noun Joe, exact case after stripping, and the program prints a warning line and ends after a one second pause. Any other noun ends with a hint pointing at that secret. If the input closes early at any prompt, the program prints Input closed, ending program and exits with status 0.

Third page: running it

Python 3 required, standard library only, no extra libraries. Every run starts fresh and asks again.

python3 madlibs.py

Tests live in test_madlibs.py and run with python3 -m unittest, covering the story text, the secret noun, and early end of input. The story builder sits in its own function in madlibs.py, separate from the prompts, so it can be tested directly.
